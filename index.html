02 — Einbindung

In 60 Sekunden live

Einen Link in den <head> einfügen — das war's. Kein npm, kein Build, kein PostCSS.

01
Theme per Link einbinden
Tausche [Theme] gegen einen der 10 Theme-Namen aus. Groß-/Kleinschreibung beachten.
html <!-- Im <head> deiner HTML-Datei --> <link rel="stylesheet" href="https://aeropus.vercel.app/cssapi/Dark_Forest">
02
Theme wechseln
Einfach den Theme-Namen im href tauschen — alle Klassen bleiben identisch, nur die Design-Token ändern sich.
html <!-- Vorher --> <link href="…/Dark_Forest"> <!-- Nachher --> <link href="…/Light_Sage">
03
Theme per JavaScript wechseln
Dynamischer Theme-Switch zur Laufzeit — ideal für einen Dark/Light-Toggle oder User-Präferenzen.
js function setTheme(name) { const link = document .querySelector('link[rel="stylesheet"]'); link.href = `https://aeropus.vercel.app/cssapi/${name}`; } // Beispiel setTheme('Dark_Ember');
04
Vollständiges Seiten-Template
Minimales Grundgerüst mit Navbar, Main-Container und Footer — alle semantischen Klassen vorbelegt.
html <link href="…/Light_Sage" rel="stylesheet"> <nav class="navbar"> <div class="navbar-inner"> <a class="navbar-brand">Brand</a> </div> </nav> <main><div class="container"> <!-- Inhalt --> </div></main> <footer class="footer">...</footer>
Alle Theme-Namen
Verfügbare Werte für [Theme] in der URL aeropus.vercel.app/cssapi/[Theme]:

Dark_Bold · Dark_Modern · Dark_Sporty · Dark_Forest · Dark_Ember

Burger-Menü aktivieren (JavaScript)
js const btn = document.getElementById('burger-btn'); const nav = document.getElementById('main-nav'); btn.addEventListener('click', () => { const open = nav.classList.toggle('open'); btn.classList.toggle('is-open', open); btn.setAttribute('aria-expanded', String(open)); }); // Schließen bei Link-Klick nav.querySelectorAll('a').forEach(a => a.addEventListener('click', () => { nav.classList.remove('open'); btn.classList.remove('is-open'); }) );
Toast-Benachrichtigung auslösen (JavaScript)
js // HTML: Container-Div an beliebiger Position im Body // <div class="toast-container toast-top-right" id="tc"></div> function showToast(type, msg, duration = 4000) { const el = document.createElement('div'); el.className = `toast toast-${type}`; el.innerHTML = ` <div class="toast-body"> <div class="toast-title">${type}</div> <div class="toast-message">${msg}</div> </div> <button class="toast-close">✕</button> <div class="toast-progress" style="animation-duration:${duration}ms"> </div>`; const dismiss = () => { el.classList.add('toast-hiding'); el.addEventListener('animationend', () => el.remove(), { once: true }); }; el.querySelector('.toast-close') .addEventListener('click', dismiss); document.getElementById('tc').appendChild(el); setTimeout(dismiss, duration); }
